## Steps
1. Check whether the problem affects the desktop app, the web app or both.
2. Confirm the user's licence and mailbox status in the admin portal.
3. Restart Outlook and recreate the profile if only the desktop app is affected.
4. Check mail flow for bounce messages.
## Escalate when
- The mailbox is not found.
- Many users cannot send or receive mail.
