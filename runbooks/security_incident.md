## Steps
1. Ask the user to stop using the affected device and not to delete anything.
2. Record the sender, subject and time of any suspicious message.
3. Hand over to the security team straight away.
4. Do not reset passwords until the security team agrees.
## Escalate when
- Always. This category is never closed at first line.
