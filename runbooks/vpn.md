## Steps
1. Confirm the user has working home internet by opening a public website.
2. Ask the user to close and reopen the VPN client and try again.
3. Check the user's account is active and not locked.
4. Reinstall the VPN profile if the error persists.
## Escalate when
- Many users report VPN failures at once.
- The error mentions a certificate or gateway.
